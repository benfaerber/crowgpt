Scan a crow

Give it a photo and it names the crow. Give it a recording or a video and CawDex finds every corvid call in the sound, names the species, labels the call type, and lays it all out on a timeline you can play.

  • A photo which corvid is it?
  • A recording every call, on a timeline
  • A video its sound, read the same way

What happens to your file

It goes to the project's server and is read once. What happens next is your choice, made with the box above for each file.

Unticked, the file is deleted the moment the scan finishes. The result is kept for an hour so this page can show it, then deleted too. Nothing is added to the project's data or used for training.

Ticked, the file is kept as you uploaded it, with what the scan said about it, and may be used to train and test the project's models. That includes anything inside the file: a photo's own GPS tags, or voices in a recording. Please only tick it for files that are yours to share. The box starts unticked every time.

It goes to the project's server, is read, and is kept. Scanning is free, and keeping the file is what the project asks in return: the file as you uploaded it, with what the scan said about it, may be used to train and test the project's models.

That includes anything inside the file: a photo's own GPS tags, or voices in a recording. Please only scan files that are yours to share.

A kept recording or video gets a "Label this recording" link, where you can say which calls the scanner got right and what was happening. This browser remembers the recordings you kept so the page can show them again; the link is the only way to reach one, so share it only with people you want labelling it.

A file the scanner could not read is never kept, and neither is one that arrives when the project's space for contributed files is full.

If the location box is ticked, an approximate location goes with the file: a city-level estimate made from your internet address, not your device's GPS. It is kept with a kept file and otherwise deleted with the result.

The internet address a file is uploaded from is recorded with every scan, so that abuse of an open upload page can be traced and stopped. It is deleted with the result after about an hour, and stays with a kept file for as long as the file does. It is never shown on the site or published.

How much to trust it

The photo model knows nine corvids and is right about nine times in ten when it knows where the photo was taken. American and Fish Crows, and Common and Chihuahuan Ravens, look alike enough that it confuses them where their ranges overlap. The sound model reads call types best for the American Crow; for a species it has no call-type model for, it reports the species alone.
